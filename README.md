# Тестирование сайта https://planetexotic.ru/
## Тест-кейсы

| ID | Модуль | Что проверяем | Приоритет | Ветка |
| :--- | :--- | :--- | :--- | :--- |
| **TC-01** | Информационный баннер | 1. Видимость и читаемость текста объявления.<br>2. Кликабельность ссылок внутри баннера.<br>3. Адаптивность (вёрстка не ломается на 375px, 768px, 1920px). | Средний | `feat/tc-01-banner` |
| **TC-02** | Шапка сайта (Header) | 1. Верхнее меню (О нас, Доставка, Контакты): кликабельность.<br>2. Контактный телефон (наличие `href="tel:"`).<br>3. Иконки соцсетей (VK, YouTube, Telegram) ведут на нужные ресурсы. | Высокий | `feat/tc-02-header` |
| **TC-03** | Строка поиска | 1. Ввод случайных символов (пустой результат).<br>2. Ввод неполного названия (работает автодополнение и поиск). | Высокий | `feat/tc-03-search` |
| **TC-04** | Избранное и Корзина | 1. Добавление товара: счетчик увеличивается.<br>2. Добавление в избранное (иконка меняет цвет).<br>3. Сохранение данных в cookie (товары не пропадают после `reload`). | Высокий | `feat/tc-04-cart` |
| **TC-05** | Сортировка каталога | 1. По цене (возрастание).<br>2. По цене (убывание). | Средний | `feat/tc-05-sorting` |
| **TC-06** | Карточка товара | 1. Отображение изображения, названия и цены.<br>2. Кнопка «Подробнее» открывает страницу с правильным заголовком.<br>3. Отображение спец-маркера (снежинка) у замороженных кормов. | Высокий | `feat/tc-06-product` |
| **TC-07** | Виджет чата | 1. Открытие виджета (зеленый круг).<br>2. Ссылки Telegram и Max корректны.<br>3. Кнопка «Отправить» активна только при чекбоксе согласия. | Средний | `feat/tc-07-chat` |
